  owns a 32-byte display name followed by `SaveTheGame`; load is available from
  both the startup and in-game panels, and a successful load enters play
  immediately. Existing-slot replacement asks for confirmation. Empty slots
  remain visible but cannot be loaded.

  statics, doors, and active pushwall state. The port has equivalent

  explicit layout identifier, record sizes/capacities, payload checksum and
  footer. Decode is transactional: validate the entire image, level,
  difficulty, counts, actor links/state ids, map coordinates, door actions,
  static records and pushwall bounds before publishing a byte of gameplay
  state. Missing, truncated, corrupt, incompatible or semantically invalid
  slots remain unavailable and cannot disturb the current game.

  current floor/difficulty, eight `LevelRatios`, player pose, level timer and
  random index, mutable tile/area maps, all 150 stable actor slots plus live
  list metadata, 64 doors and timers, 400 statics, and the complete pushwall
  payload. Transient input, callback, render-owner, audio-arbitration and
  scratch fields are deliberately excluded and reinitialized.
- Restore order is fixed: load and validate the save image; select and load
  the canonical W3L/assets for its floor and difficulty; publish the saved
  authoritative state; rebuild derived occupancy/collision/reachability;
  reset transient simulation and combat state; reset the VDPlet mirror; then
  submit one complete renderer snapshot before accepting controls. This keeps
  the write-only renderer subordinate to eZ80 state and prevents a partial or
  stale frame from becoming visible.
