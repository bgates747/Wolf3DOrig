## Recorded-demo abort routing correction

- `WL_MAIN.C::DemoLoop` distinguishes a naturally exhausted `PlayDemo` from
  `playstate == ex_abort`: natural completion restarts the title/credits/
  scores cycle, while local input enters `US_ControlPanel` immediately. The
  port collapsed both outcomes into `w3d_demo_finished` and therefore sent a
  key-aborted demo back to the title.
- Recorded-demo state now carries a separate transient abort reason. Physical
  input sets finished+aborted while deliberately keeping demo-local Escape
  out of the application exit latch; natural stream exhaustion sets finished
  alone. Gameplay teardown samples
  the reason before clearing demo state and routes directly to the main menu
  only for the abort case. The direct demo fixture pins natural/aborted
  differentiation and reset-on-cancel; visual acceptance still exercises the
  complete renderer-to-shell route.
