## Production eZ80 descriptor and batch serializer

The conditional VDPlet build now includes a production serializer without
changing the accepted standalone default. `wolf3d_vdplet_batch.inc` emits the
exact 24-byte descriptor and schema-1 full/dirty buffers directly from the
authoritative gameplay state. The actor SET path was factored through one
shared `w3d_build_actor_wire_record` routine, so standalone commands and
VDPlet records use identical state/shape/position/facing/rotation conversion.

The ownership rule is deliberately stronger than dirty-flag rollback. A
prepared batch and candidate generation are immutable until accepted. The
first successful RUN submission consumes only the captured dirty snapshot.
Simulation may accumulate new dirt while that RUN is in flight. If the module
returns an error, the exact same bytes are retried without restoring old flags
over newer state and without clearing dirty state again. Success commits the
candidate generation and releases staging for the next delta. Generation wrap,
double submission, invalid lifecycle transitions, and empty deltas are refused.

not a Python reconstruction. Its generation-1 E1L1 snapshot contains the level,
