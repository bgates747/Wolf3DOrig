## VDPlet feasibility result

The completed study recommends a conditional go. ABI 1.3 buffer leases and
generic RGB222 pixel output are sufficient for a first prototype without a
Wolf-specific runtime extension. The accepted render algorithms can be
retained, but firmware-private Canvas/VGA/buffer classes must be replaced by a
compact module state and an approximately 90 KiB application-owned software
frame workspace.

The current renderer is not directly admissible: its existing state and tables
greatly exceed the VDPlet 16 KiB combined static-data allowance. The proposed
compact world mirror, quarter-wave trigonometry table, and external scratch
space make a fit credible, subject to a real link and stack receipt. Remaining
gates are module admission, physical double-buffered generic-pixel
qualification, physical render-performance measurements, and complete
lifecycle/error/exit qualification. The migration document records the staged
implementation plan and the mandatory Author review stop; no implementation
files were changed during this study.
