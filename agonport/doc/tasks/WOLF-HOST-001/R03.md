# Qualify an attached observer in its own foreground process group

R02 proves a direct sender record but loses group attribution when the tracer
is in the signalled group. Do not block fatal signals, daemonize, change service
policy, switch Codex process-control APIs or infer a historical cause. No
hardware trial is selected. This is a new bounded host-only qualification.

- [x] HOST-R03-01 — Freeze exact source and installed native Python/strace
  identities. Keep the observed disposable child on Extender Python3.14 and
  normal default SIGTERM behavior; parent uses native pidfd for exit proof.
- [x] HOST-R03-02 — Start ONLY an owned child in a new group, then a foreground
  strace observer in a DIFFERENT new owned group attached to that exact child
  PID. Verify actual /proc TracerPid before controlled input. No -f: no attach
  to app-server, other threads, child descendants or another agent's process.
- [x] HOST-R03-03 — Four actual cases: normal exit with no false signal record;
  direct child SIGTERM with exact sender; child-group SIGTERM with exact sender;
  observer-only SIGTERM with actual detach and observed child still alive until
  explicit owned cleanup. Do not silently replace a refused attach or weaken
  any predicate. Stop first unexpected, retain logs and release.
- [x] HOST-R03-04 — Publish actual coverage/limits and return it for source
  coordination before any separately selected real observer/physical contract.

Maintain120s whole,20s case,5s ready/attach bounds, serial children,80C stop and
512MiB available RAM floor. Each PID/group is created by this helper and checked
against its ready record; no host-wide signalling or unrelated PID selectors.
Wait/reap the observed child and observer in the parent. An observer cancellation
must not cancel its target. Target-group signalling must terminate its target
normally; source evidence must name the actual test sender PID/UID. A ptrace or
pidfd refusal stops the case; no privileged workaround or installed component.

Use existing --interruptible=1, trace=none, signal=SIGTERM and -p exact-owned-PID.
This prospective controlled qualification is not a reproduction of the unexplained
long host failure and makes no timing or repair claim. A future controller would
need an explicit pre-I/O attachment handshake, observer-liveness checks before
new submissions, preserved original foreground handles and ordinary failure/
restoration custody. None is implemented or dispatched by this contract.

Actual391 passed all four cases and released; see [RESULT03.md](RESULT03.md).
