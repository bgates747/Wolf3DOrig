# Development log — 2026-08-13

## Collision requalification candidate

TODO 1 resumed after play testing showed that actor and blocking-decoration
contact distances were roughly twice as large as desired while the accepted
wall and moving-door behavior remained sound.

The candidate implementation keeps the 512-byte blocking-static bitset as the
common-path broad phase and builds an 8 KiB dense `uint16` tile-to-static table
once per level attempt. An empty lookup entry is zero; a blocking tile stores
its stable static slot plus one. Only a bitset hit resolves the table entry and
tests the player's center against an inclusive `0x6000` square around the
centered static. Normal movement therefore does not scan the static list.

Player-to-shootable-actor and actor-to-player physical contact now use the same
inclusive `0x6000` center-square threshold. The accepted `0x4800` player
wall/moving-door radius, pickup reach, aiming, and behavioral ranges remain
separate. The patrol regression also exposed an older coupling in the fully
open door close-start guard: adjacent actors must retain original Wolf3D's
`0x5800` `MINDIST` boundary. That actor-only rule now has its own bounds helper
and no longer inherits the tuned player radius.

## Episode 1 victory and application-shell candidate

The original E1L9 map does not contain an elevator switch. Its three exit
cells are plane-1 value 99 at `(33,7)`, `(34,7)`, and `(35,7)`. The W3L
generator now preserves that otherwise-discarded metadata as
`W3D_PATH_VICTORY` (`0xfe`) in the existing 4 KiB path section, with no package
format or version change. Accepted player movement onto one of those cells
latches a distinct VICTORY completion, hides the weapon, and stops the rest of
that simulation quantum before pickups, combat, actors, or a second movement
axis can run. Existing normal-elevator and secret-floor routes remain intact.
A defensive NORMAL completion on zero-based floor 8 is also classified as
victory, so E1L9 can never accidentally advance to secret floor 9.

Ordinary floor transitions remain inside the session. Victory first drains any
older asynchronous render, submits and drains exactly one terminal snapshot so

and callback ownership, and returns to the application shell without loading a
level-09 package. The current first slice acknowledges Episode 1 completion in
