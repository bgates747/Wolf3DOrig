# Development log — 2026-08-13

## Collision requalification candidate

TODO 1 resumed after play testing showed that actor and blocking-decoration
contact distances were roughly twice as large as desired while the accepted
wall and moving-door behavior remained sound.

The candidate implementation keeps the 512-byte blocking-static bitset as the
common-path broad phase and builds an 8 KiB dense `uint16` tile-to-static table
once per level attempt. An empty lookup entry is zero; a blocking tile stores
its stable static slot plus one. Only a bitset hit resolves the table entry and
tests the player's center against an inclusive `0x6000` square around the
centered static. Normal movement therefore does not scan the static list.

Player-to-shootable-actor and actor-to-player physical contact now use the same
inclusive `0x6000` center-square threshold. The accepted `0x4800` player
wall/moving-door radius, pickup reach, aiming, and behavioral ranges remain
separate. The patrol regression also exposed an older coupling in the fully
open door close-start guard: adjacent actors must retain original Wolf3D's
`0x5800` `MINDIST` boundary. That actor-only rule now has its own bounds helper
and no longer inherits the tuned player radius.

## E1L2 stale-tilemap diagnosis and accepted fix

TODO 2b was reproduced with a reversible generator switch which starts E1L1
inside its ordinary elevator at `(25,47)`, facing east toward the exit switch.
One Up-arrow press now reaches the transition without replaying the floor. The
original GAMEMAPS data is untouched; omitting
`--diagnostic-e1l1-elevator-start` restores the real `(29,57)` spawn.

The destination package, pose, and CPU reseed path were all correct. E1L2's
only player marker is `(16,61)`, facing north; that cell is open floor in E1L2
and every generated/staged difficulty package agrees. The decisive mismatch is
that the same coordinate and its surrounding region are wall texture 1 in
E1L1.

The stock VDP `BUFFERED_WRITE` operation appends a stream to an existing buffer
ID. Floor transition uploaded E1L2 to the existing tilemap buffer 2 without
clearing E1L1, producing streams `[E1L1, E1L2]`. Wolf3D's renderer deliberately
reads stream zero, so it combined the correct E1L2 pose with E1L1's wall field.
That exactly explains the observed gray enclosure. Image textures were not
affected because the AGNB loader already clears reused buffers.

The accepted fix introduces one common tilemap replacement helper used by
initial game entry and ordinary/secret floor transitions: clear buffer 2,
reload its ID after the clobbering helper call, then write exactly 4096
destination bytes. Death respawn correctly continues to reuse the resident map.
No firmware change is required.

Regression coverage now includes the exact cross-floor geometry signature and
requires the production clear-before-write helper contract. It counts one map
replacement on victory startup and two on an ordinary/secret transition.
Focused host tests passed 7 tests plus 10 subtests; production routes passed
`0 -> 1`, `0 -> 9`, `9 -> 1`, and E1L9 victory; the application assembled at
105,122 bytes. Interactive reproduction then transitioned into the correct
E1L2 starting room. TODO 2b is complete and has been removed from the active
list.

The temporary spawn remains deliberately uncommitted for further
floor-transition presentation experiments.

## Original-style floor-completion intermission candidate

TODO 2c promotes the ordinary/secret floor boundary from an invisible load
pause to the original game's visible completion presentation.  The canonical
implementation is `LevelCompleted` in `orig/src/WOLFSRC/WL_INTER.C`: it runs
after the completed frame is drained but before the destination floor is
selected or loaded.  The bundled v1.4 archive does not contain a complete
intermission bitmap.  It contains BJ's two breathing portraits and a dedicated
16-pixel picture alphabet, from which the DOS code composes the screen.

The historical generated graphics headers do not number this archive
correctly.  Direct dimension and visual inspection established the actual
bundled contract: chunks 55--96 are BJ, colon, digits, percent, A--Z,
punctuation, and BJ's alternate breathing frame.  They now occupy their
collision-free `$4000 + chunk` HUD buffers; `$4100` and `$4101` contain durable
320x200 ordinary and secret-floor base composites reconstructed at the exact
original coordinates over VGA palette colour 127.  The original status-bar
buffer remains `$4062` and is plotted at y=200 for the Agon's 320x240 layout.

The runtime intermission begins only after asynchronous render ownership has
returned to NONE, while the source W3L package and its counters are still
authoritative.  It switches to a stable single-buffered mode and immediately
draws the source floor number, elapsed `MM:SS`, Episode 1 par time, and final
kill/secret/treasure ratios. Destination loading begins as soon as that first
complete picture is visible. Every finalized destination bitmap becomes a
nonblocking timing/input boundary: it polls Escape, release-gates and latches
a fresh non-Escape acknowledgment, and advances BJ's two-frame breathing
animation at a divided cadence. The held elevator-use key therefore cannot
also dismiss the screen. If loading finishes before acknowledgment, only then
does the screen wait for a fresh acknowledgment; one received during loading
eliminates the extra press and requires only its safe release. Mode 8+128 is
restored only after the complete destination package,
images, replacement tilemap, and acknowledgment are ready, immediately before
the reset render. Victory bypasses this floor screen for its distinct
episode-ending lifecycle.

Escape is now an application-global clean-exit request rather than a local
menu-back action. Shell input, textual bootstrap AGNB callbacks, intermission
loading callbacks, and the gameplay hot loop all route it to the same outer
shutdown: active audio/render callbacks are relinquished when present, the
caller's original base video mode is restored and cleared, and the existing
`Thanks for playing Wolf3DOrig!` line is emitted above the MOS prompt. The
abortable AGNB extension preserves the legacy callback-result-ignored ABI and
adds explicit image/audio entry points whose nonzero callback result closes
the FIL and returns dedicated error 14.

Elapsed time is counted at the accepted 30 Hz simulation seam and clamps at
the original display maximum of 99:00.  Kill total is derived from immutable
source actor seeds carrying `FL_SHOOTABLE`; treasure total uses exactly the
original cross/chalice/bible/crown/full-heal item set.  Pushwalls are not yet
implemented or retained as discoverable state, so the honest current secret
ratio is zero.  This first slice is silent and presents final values
immediately. BJ's two-frame breathing animation is now live at finalized-asset
boundaries; the original count-up, music/SFX, time/100-percent bonus awards,
and stored endgame ratios remain later fidelity work.
