# Wolf3D shell image overrides

Place only durable, hand-edited shell PNGs here. Filenames and dimensions must
match the generated originals under
`agonport/assets/generated/wolf3d/shell/orig/`. The durable
`build_shell_assets.py` script prefers a matching override and otherwise
extracts the corresponding picture from `orig/data/VGAGRAPH.WL1`.

Generated and converted intermediates remain under
`agonport/assets/generated/wolf3d/shell/` and must not be edited directly.
